## Review (delegate subagent) and what came of it

The review found HS6, HS13 and HS8 sound. It found five defects, each now fixed with a test case:
1. HS9 missed `config set` behind a wrapper or a flag's value, a registry host with a context word, and a here-string
   into `--password-stdin`.
2. HS5 applied the saved level with another model the caller named, or a level the model lacks.
3. HS7's default crew harness came from a static list, not the harnesses this wisp has.
4. `delegate` waited on an empty id, and read an answer that wasn't a list as "Nothing was delegated".
5. A pre-existing leak, `sudo docker login -p`, is fixed by the same wrapper rule.

Nits fixed:
- The sandbox refusal no longer offers Auto while it's off.
- `taps_are_personal` is an allow-list (default deny for a channel a plugin adds).
- The grid reads `server.json` with `tokio::fs`, from any process the box ran.

Nits left:
- `Phone::session` now makes one more `runtime.turns` read per call (GitHub's comment check calls it for up to 20
  tasks).
- A one-letter word after an unquoted prompt (`wisp why does grep -l miss files`) is now refused as a stray flag, with
  the `--` way out; the CHANGELOG says so.
