## Security review (delegate) and what it changed
- **Fixed:** a password containing `@` was no longer masked (the `@` stop is gone; a mask isn't re-masked instead);
  `sudo -E`/`sudo -u root`/`env -i` before a tool hid it from the flag rules; `echo … | htpasswd -i` and digit-only
  passwords in password-only positions leaked; the launch folder stayed on a failed spawn, a cancel or a dropped drive
  (drop guard + start sweep); Codex's `shell_environment_policy.exclude` replaced the user's own list (gone: the header
  variables are `…TOKEN…`, which Codex's default policy already keeps from its shells); a connector env named like
  Codex's own variables overrode Codex (not forwarded); an agent's token could mark a guard question (refused); a guard
  task created but not yet asking when the call went was left held and unmarked (settled by the drop guard).
- **No defect found** in IS1's other paths (Slack, Discord, push, email, `runtime.answer` from plugins) or IS2's turn
  paths (every turn goes through `start_claimed`).
