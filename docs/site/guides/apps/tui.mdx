`wisp tui` is wisp full screen in your terminal. It shows the same tasks as the app, live, and does what the app
does: start tasks, follow them, answer questions, review changes. Nothing is polled; every key answers at once.

```sh
wisp tui
```

It talks to the wisp server like the app and the CLI do, and starts it if it isn't running.

## The screen

- **Tasks**, on the left, in the same sections as the app.
- **The open task:** its live transcript, step by step, with its state in the header.
- **A side pane:** the changes (**d**) or the Thread pane with the task's Notes (**t**).
- **The composer** at the bottom, and a status bar under it.

**Tab** moves between zones. **[** and **]** narrow or widen the focused one (or drag its border). The mouse works
too. Press **?** for the keys at any time.

## The palette

**Ctrl-K** (or **:**) finds anything by name: a task, a view, a setting, or any wisp command. Commands show by
their title with the words you'd type in the CLI at the right, for example *Add a computer · machines add*.

## Commands with `/`

In the composer, any CLI command runs as `/<plugin> <verb> …`, with the same words and flags as `wisp <plugin>
<verb> …`. As you type, the line under the box shows how to use it.

```text
/machines add --name studio --address me@studio
/goal set --text "all tests pass"
/runtime set-mode --mode plan
```

When the command acts on a task, the open task is the one it acts on, unless you give an id. With no task open
it asks you for one.

## Views

**g** and a letter opens a view: a table over the same data as the app's screens. The footer lists the letters
for the selected row.

| View | Go | Row actions |
| --- | --- | --- |
| Crew | **g c** | **n** new member, **a** give a job, **c** check in, **w** wake, **p** pause, **u** resume, **x** remove |
| Automations | **g a** | **f** fire, **t** test |
| Machines | **g m** | **c** connect, **x** disconnect |
| My Stuff | **g s** | **l** launch, **d** remove |
| Settings | **g ,** | |
| Repo history | **g h** | |

**g t** goes back to your tasks. Plugins can add views of their own the same way.
