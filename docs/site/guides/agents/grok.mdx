wisp runs Grok Build, the `grok` command, in the background, one worktree per task, on your own xAI account.

## What you need

The `grok` command on your `PATH`. Install it from [x.ai/cli](https://x.ai/cli).

## Sign in

<Tabs syncKey="way">
<TabItem label="App">
Avatar → **Settings** → **Agents** → **Sign in** next to Grok. Open the sign-in page and enter the code wisp shows.
Or press **Keys** and paste an xAI key.
</TabItem>
<TabItem label="TUI">
Send `/accounts login start grok default` and follow the link it gives.
</TabItem>
<TabItem label="CLI">
```sh
wisp accounts login start grok default
wisp accounts login status grok default
```
Or run `grok login` yourself, or set `XAI_API_KEY`.
</TabItem>
</Tabs>

## Pick it, its model and its effort

wisp reads `grok models` and the levels each model takes. Effort: `low`, `medium`, `high`, `xhigh`.

<Tabs syncKey="way">
<TabItem label="App">
Click the harness chip in the New task footer, pick **Grok**, then a model and a thinking level.
</TabItem>
<TabItem label="TUI">
Send `/runtime set-agent --agent grok` to move the open task to Grok.
</TabItem>
<TabItem label="CLI">
```sh
wisp "profile the slow import" --agent grok --effort high
```
</TabItem>
</Tabs>

Modes: **Plan**, **Edits**, **Full auto** (`--mode plan|edits|auto`). A run without a terminal refuses what needs
approval. wisp shows each refusal on the task as blocked.

## What wisp adds for Grok

- wisp's tools (asking you a question, and the rest) reach Grok through an agent definition wisp writes for the
  run.
- Your prompt and wisp's rules go in as files, not on the command line.

## Open in Grok

<Tabs syncKey="way">
<TabItem label="App">
The task's **⋯** menu → **Open in Grok** (key **T**).
</TabItem>
<TabItem label="TUI">
Press **o** in the open task. Grok's own screen takes no first prompt, so wisp types it in for you.
</TabItem>
<TabItem label="CLI">
```sh
wisp runtime resume-command <id>
```
</TabItem>
</Tabs>
