Wisp Agents runs Claude Code, Codex, Cursor, opencode, Antigravity, Grok and Copilot from one place: the desktop app, the
browser, the terminal UI, the command line, your phone, or your own agent. It keeps every task they did next to the
code they wrote. Every guide shows each step four ways: the **Desktop app** (the browser is the same), the **Phone app**, the
**TUI** and the **CLI**.

<CardGrid>
  <Card title="Declare" icon="document">
    Your agents, crew, machines, skills, MCP servers, rules and workflows as files in your repo's `.wisp/`
    folder. Review them in a pull request like any code.
    [Write your setup as code](/docs/concepts/formulas/)
  </Card>
  <Card title="Run" icon="rocket">
    Any agent, many at once, each in its own git worktree, on this computer, your other computers or in the
    cloud. Follow up, set goals, compare two agents on the same task.
    [Run a task](/docs/guides/run/run-and-follow-up/)
  </Card>
  <Card title="Track" icon="magnifier">
    Every task is a file: what was asked, what the agent said, the code it wrote. `wisp blame` tells you which
    task wrote a line and why.
    [Track agent work](/docs/guides/track/track-agent-work/)
  </Card>
  <Card title="Make it yours" icon="puzzle">
    Everything in wisp is a plugin. Add a setting, a pane, a command or a whole channel with the same API the
    built-ins use.
    [Make wisp your own](/docs/plugins/make-wisp-your-own/)
  </Card>
</CardGrid>
